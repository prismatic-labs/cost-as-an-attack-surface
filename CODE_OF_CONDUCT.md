# Code of conduct

This workshop is a technical discussion of a defensive control. Participation, issues, and contributions are welcome from people with different experience levels.

## Expected behaviour

- Critique ideas and code specifically.
- Assume mixed experience. Define terms when you introduce them.
- Keep demonstrations inside the local sandbox in this repository.
- Give credit when you use someone else's writing, model, or measurement.

## Unacceptable behaviour

- Harassment, discrimination, or personal attacks.
- Publishing someone else's private information.
- Using these materials to attack, scan, or generate cost against a system you do not operate and do not have permission to test.
- Raising or bypassing the hard safety ceilings in order to turn the exercise into an unbounded workload.
- Presenting the illustrative cost figures as invoices or as a vendor's current prices.

## Scope

The experiment is intentionally local. Mock tools do not call networks. A contribution that adds arbitrary URL targets, credential collection, or an unbounded loop will be rejected.

## Reporting

If the project has a public repository, report conduct concerns privately to the maintainers through that repository's security or contact channel. Until a remote exists, raise the concern with the OxCyber session organisers or with Prismatic Labs as the organisation maintaining these materials.

Maintainers will respond by clarifying the expected behaviour, editing the materials, or rejecting a contribution. This process is not a legal proceeding.
